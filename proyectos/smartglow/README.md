# SmartGlow 💡

**Sistema de iluminación inteligente**

**Proyecto académico colaborativo | Junio 2025**

## Descripción

SmartGlow es un proyecto universitario enfocado en la automatización residencial. Consiste en un sistema que permite controlar la iluminación de diferentes habitaciones de una vivienda mediante una aplicación móvil Android, conectada por Bluetooth a un Arduino UNO.

El proyecto integra desarrollo de software, programación de microcontroladores y electrónica para ofrecer una solución de control de iluminación.

## Objetivo

Desarrollar un sistema de iluminación inteligente que permita controlar las luces de una vivienda desde una aplicación móvil y programar horarios de encendido y apagado automático.

## Tecnologías y herramientas

- **Kotlin:** desarrollo de la aplicación Android.
- **Android Studio:** entorno de desarrollo móvil.
- **XML:** diseño de interfaces.
- **PHP:** desarrollo del backend.
- **MySQL:** gestión de base de datos.
- **Arduino UNO:** control del circuito electrónico.
- **Arduino IDE:** programación del microcontrolador.
- **Bluetooth HC-05:** comunicación entre la aplicación y Arduino.

## Funcionalidades implementadas

- Control de encendido y apagado de luces por habitación.
- Comunicación Bluetooth entre la aplicación Android y Arduino UNO.
- Programación de horarios para el encendido y apagado automático de las luces.
