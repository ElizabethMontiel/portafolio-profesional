### 💡 SmartGlow
**Aplicación móvil | Proyecto universitario | Junio 2025**

Solución de automatización residencial (IoT) para el control remoto y programado de iluminación mediante tecnología Bluetooth.

**Características:**
- Comunicación entre una aplicación móvil y el hardware Arduino UNO.
- Configuración de horarios para la activación de luces.

- Kotlin
- Android Studio
- XML

### 🍰 Montelia
**Sitio web de repostería | Proyecto personal**

Proyecto personal de desarrollo web enfocado en la presentación y promoción de productos de repostería.

El objetivo es ofrecer un sitio web donde los visitantes puedan consultar los postres disponibles y realizar pedidos mediante WhatsApp.

**Características desarrolladas:**
- Catálogo de postres.
- Panel administrativo para gestionar productos.
- Administración de testimonios.
- Inicio de sesión administrativo.
- Integración de pedidos mediante WhatsApp.
- Diseño adaptable a computadoras y dispositivos móviles.

**Tecnologías utilizadas:**
- PHP
- MySQL
- HTML
- CSS
- JavaScript
